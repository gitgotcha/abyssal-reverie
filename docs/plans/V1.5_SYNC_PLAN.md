## 0. 范围与已定决策

**做**：事件化增量双向同步（outbox + 游标）、服务端事件去重、冲突与删除墓碑、重叠片段「待核对」、设备管理、同步状态文案。

**不做**：在线权威计时与排行榜（如有需要另行验证需求）、运行中计时器的跨设备接力转移（本版另一设备只显示状态）、树与成长同步（第 5 项不在范围）。

| # | 决策 | 状态 |
|---|---|---|
| D-1 | 同步单位 = **事件**（业务写入与待同步事件同事务进入 outbox），服务端按 `user_id + event_id` 去重；不做整库上传；拉取用游标续传 | 待确认 |
| D-2 | 合并规则按数据类别分治（§2 表）；同字段并发冲突**不自动裁决**，保留双方让用户选择；删除用墓碑防止复活 | 待确认 |
| D-3 | 个人总时长按**有效片段时间并集**计算；两设备离线重叠专注不声称完全阻止重复，同步后标记重叠待核对，原始记录保留 | 待确认 |
| D-4 | 运行中计时器仅当前设备可控制；其他设备只读显示状态 | 待确认 |
| D-5 | 同步失败绝不阻塞本地专注；全局状态条文案化，不用弹窗打断 | 待确认 |

## 2. 合并规则表（实现与测试的对照基准）

| 数据 | 规则 | 关键测试 |
|---|---|---|
| 已结束会话 / 专注片段 | 稳定 ID 去重；保持原记录；修正走单独修正事件，不覆盖原始 | `duplicate_session_imported_once`、`correction_event_does_not_rewrite_original` |
| 任务标题/预算/完成状态 | 字段级 `rev` 比较：不同字段可合并；同字段并发 → 冲突记录，UI 保留双方让用户选 | `different_fields_merge`、`same_field_conflict_surfaces_choice` |
| 删除 | 墓碑（`deleted_at` + 墓碑事件）；旧设备离线修改后上线**不复活**已删除项，转为「删除 vs 修改」冲突可见 | `deleted_task_not_resurrected` |
| 字体、默认时长、偏好 | 字段级版本；字体不可用时本机回退；**窗口坐标不同步**（仅设备本地） | `settings_field_merge`、`window_position_never_synced` |
| 档案/成长类数据 | 本版范围外（S-1）；个人总时长由片段并集推导，服务端不存第二份总量 | `total_seconds_is_union_of_segments` |
| 正在运行的计时器 | 仅发起设备可控制；其他设备从 `timer-changed` 广播读状态 | `remote_device_sees_running_state_readonly` |

## 6. 阶段 E — 发布与实机验收

1. 版本号、CHANGELOG、REGRESSION_REPORT、ACCEPTANCE_GUIDE（同步语义与限制如实描述）。
2. 双设备实机矩阵：

| 案例 | 预期 |
|---|---|
| 断网专注 → 恢复联网 | 事件全部补传，无丢失、无重复、时长不翻倍 |
| 同一记录重复导入 / 重试上传 | 去重，时长与统计不变 |
| 两台设备离线同段时间专注 | 原始记录都保留；总时长按并集；重叠可见待核对 |
| 设备 A 改标题、设备 B 改预算（离线） | 字段合并成功，无冲突 |
| 设备 A、B 同时改标题 | 冲突可见，用户选择，不静默覆盖 |
| A 删除任务、B 离线改它后上线 | 不复活；「删除 vs 修改」待核对 |
| A 退出后 B 登录（同机） | 隔离不变量成立；队列不以 B 身份上传 A 数据 |
| 移除设备 | 该设备停用同步、数据保留、提示明确 |
| 服务端不可达期间 | 本地一切功能正常，状态条显示待同步 N 项 |

## 7. 门禁与风险

- 门禁：Rust + 服务端契约测试 + `pnpm verify`；双设备实机矩阵全过；故障注入（同步中途杀进程、事件负载损坏跳过并告警）。
- 风险：
  - **事件重放顺序**：lamport + 服务端接收序双序；同一实体的乱序到达必须在 `apply_*` 幂等化，测试覆盖乱序用例。
  - **首次全量重放体量**：10 万会话用户的事件流可能过大——B4 的快照 + 增量方案是备选，需在阶段 B 结束前按真实数据量决定。
  - **冲突 UI 复杂度**：本版只覆盖 §2 表列出的冲突类型；列表保持「少而准」，新类型先标记待核对不自动处理。
