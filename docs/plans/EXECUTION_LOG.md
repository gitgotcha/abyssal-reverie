5. 统计回退路径漏计会话数（无片段会话）→ 已修复并有边界测试。
6. 行内联脚本与 CRLF 混用的工程噪音：`repository.rs` 现为混合行尾（可编译，建议后续 `cargo fmt` / 规范化时统一）。
