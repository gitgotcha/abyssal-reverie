## 0. 范围与已定决策

**做**：Schema v4（类别 → 项目 → 任务 + 片段账本 + 档案字段）、预算快照与实时任务进度、运行中同钟切换任务、任务详情编辑 / 搜索 / 组合筛选 / 归档撤销、统计按发生时归属汇总、字体与可读性、`timer.rs` 死代码清理。

**不做**：植树与成长（S-1）、悬浮小窗（v1.3）、登录与云端（v1.4，仅落档案字段）、多对多关系与标签扩展、重复任务模板（第二梯队）。

| # | 决策 | 状态 |
|---|---|---|
| D-1 | 层级固定 `类别 → 项目 → 任务`，全部一对多；不引入项目分组/Section；标签保持现状不参与主层级 | 待确认 |
| D-2 | 预算在创建时冻结：`目标秒数 = 预计番茄数 × 当次设置的单次专注分钟 × 60`；修改默认时长不影响旧任务；提供显式「重算预算」，原值与变更记录保留（`budget_history`） | 待确认 |
| D-3 | 运行中切换任务改为**同钟切分**：主钟不重置，关闭当前任务片段、开启新任务片段（替换 v1.1.2 的结束并重开实现，二者用例相同） | 待确认 |
| D-4 | 30 秒资格按**会话累计有效时间**判定；会话合格后各片段按实际占用入账，片段不再单独设门槛 | 待确认 |

| D-7 | 删除任务/项目 = 可撤销归档（软删除）；历史专注记录保留并可追溯；正在专注的任务删除/归档需先暂停并明确提示 | 待确认 |
