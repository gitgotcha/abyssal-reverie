# 变更日志（Changelog）

## v1.2.0 — 2026-09-06（类别·项目·任务与计时升级）

数据层级升级为 **类别 → 项目 → 任务**，任务获得真实预算与时间片段账本。
（本版本尚未发布；实机验收由维护者确认后执行。）

### 新增
- **类别与项目**：默认类别 学习/工作/生活/其他；项目挂在类别下，任务至多属于一个项目
  （不绑定即为独立任务）；项目改名/移动类别不失效关联；项目完成率按任务数计算
  （1/3 型），存在未完成任务时拒绝直接完成项目。
- **任务预算快照**：创建时按「预计番茄数 × 当前单次专注分钟 × 60」冻结目标秒数；
  修改默认时长不影响旧任务；支持手动重算并保留变更历史（budget_history）。
- **时间片段账本（focus_segments）**：专注开始打开片段，暂停冻结，恢复开新片段；
  30 秒资格按会话累计判定，会话合格后各片段确认入账；不足 30 秒的会话片段作废。
- **运行中同钟切换任务**：切换不再重置主钟——关闭当前任务片段、开启新任务片段，
  各任务时间分别记账，个人总量按片段并集。
- **完成任务并保存（complete_task_now）**：单事务「冻结片段 + 标记完成 + 解绑任务」，
  主钟保持暂停、剩余时间保留；幂等可重试；完成后真实投入不补足预算。
- **任务管理 UI**：快速创建（标题/项目/预计番茄+分钟换算，优先级截止备注收进更多选项）、
  关键词搜索、状态与标签筛选（区分「还没有任务」与「筛选无结果」）、任务详情编辑、
  归档替代删除（可恢复、历史保留）、项目与类别管理面板。
- **统计**：项目分布改按片段发生时归属汇总（同钟切换后各归各）；新增类别分布。

### 修正
- 删除 `src-tauri/src/timer.rs`（未参与编译的死代码）。
- 全部业务表增加 `profile_id` 档案字段（v1.4 账号隔离地基，本版只有 local 档案）。

### 兼容与迁移
- 数据库 schema v3 → v4：自动升级，升级前创建时间戳副本；旧任务自由文本项目按
  trim 后完全同名归并为正式项目（近似名不合并不猜测）；历史会话回填为确认片段。
- 预算为迁移推算值并明确标注来源，不冒充精确历史。
- 备份格式仍为 v2；v2 备份可导入（新字段按默认值回填）。

## v1.1.2 — 2026-09-06（现有流程一致性）

聚焦既有流程的可信度：任务创建反馈、任务选中状态、活动记录与统计一致性、数据库版本守卫。
（本版本尚未发布；发布 EXE 实机验收由维护者确认后执行。）

### 修正
- **任务创建反馈**：保存成功后才清空标题，失败保留完整草稿并原地重试；提交中防连点
  （只创建一次）；中文输入法候选确认的 Enter 不再误提交（`isComposing` / keyCode 229 守卫）。
- **任务选中状态一致**：计时面板的高亮改为跟随后台快照（`timer.selectedTaskId`），
  不再使用本地高亮状态；空闲时点击为「待用选择」，运行/暂停中点击其他任务弹出确认。
- **运行中切换任务（新命令 `switch_timer_task`）**：单事务内按 manual_finish 语义保存当前
  会话的实际专注时长，并为新任务开启新一轮；不足 30 秒的切换记录不进入统计与活动栏；
  幂等（重放返回既有结果）；休息轮次禁止切换；暂停中切换保持暂停。
- **活动记录一致性**：内存数组统一为「最新在前」（与后台 `started_at DESC` 一致，按
  `(startedAt, id)` 排序）；完成/结束/切换记录头部插入且按会话 ID 去重——同一结束事件
  从 UI tick 与 Rust 后备事件双入口到达只出现一条；**休息轮次与不足 30 秒的完成不再
  出现在活动栏**（修正既有泄漏）；到期后统计刷新改为在完成结算之后串行执行。
- **统计口径**：总量查询改为半开区间 `[from, to)`，与每日桶一致——恰在边界 `to` 的会话
  不再造成总量与分桶不一致；日界改为日历法次日零点，夏令时切换日覆盖 23/25 小时
  （纽约 2026-03-08 / 11-01 有回归测试）。
- **数据库高版本守卫（新错误码 `DATABASE_TOO_NEW`）**：旧程序打开由更新版本创建的数据库
  时拒绝打开、不写入任何字节（含 WAL 触碰之前的早期检查）、启动时原生消息框说明后退出。
- **文案精度**：手动结束不足 1 分钟提示「已记录 X 秒」，不再把 30 秒说成「1 分钟」。

### 兼容
- 数据库 schema 仍为 v3，与 v1.1.1 完全一致，无需迁移。
- 备份格式仍为 v2。
- 行为变化：运行中点击其他任务由「仅改高亮」变为「确认后切换并保存」，已在版本说明中明示。

## v1.1.1 — 2026-09-05（发布构建修复）

修复 v1.1.0 发布包无法启动的严重缺陷。**v1.1.0 用户请直接升级**，数据格式一致（schema v3），原数据不受影响。

### 修正
- **启动黑屏 / 白屏（P0）**：`src-tauri/Cargo.toml` 缺少 `[features] custom-protocol`，
  导致发布构建不内嵌前端资源，运行时回落到开发服务器地址 `http://127.0.0.1:1420`。
  表现为空窗口且无任何错误提示。现已恢复该 feature，前端资源正确嵌入 EXE。
- **渲染失败无提示**：新增顶层 `ErrorBoundary`，React 树内任何抛错都会显示可读的错误信息、
  组件栈与「复制 / 重新加载」按钮，不再退化为一个无从下手的黑屏。

### 其他
- 版本号统一为 `1.1.1`（`tauri.conf.json` / `Cargo.toml` / `package.json` / `README.md`）。
- GitHub Release v1.1.0 已标记为「已知启动黑屏，请勿使用」并取消 Latest，原 tag 与历史保留。

### 兼容
- 数据库 schema 仍为 v3，与 v1.1.0 完全一致，无需迁移。
- 备份格式仍为 v2，v1 备份可继续导入。

## v1.1.0 — 2026-09-05（本地体验前置改造）

在 v1.0.0 离线基础上修正计时语义、统计口径与任务分类能力（规格：本地体验前置改造设计）。
**注：此版本的发布包存在启动黑屏问题，已由 v1.1.1 修复。**

### 新增
- **任务标签体系**：单一主标签（默认 学习/工作/生活/其他，"其他"为保底标签）；创建、重命名、排序、安全删除（受影响任务自动移至保底标签，历史快照永不改变）；任务按标签筛选，行内低饱和标签徽标；标签数量硬上限 100。
- **「结束」按钮**：主控制区统一为 重置 / 暂停·继续·开始 / 结束；手动结束按实际专注时长落库。
- **30 秒资格规则**：满 30 秒的手动结束才进入专注统计；不足 30 秒的记录写入数据库但不在任何页面显示（完整 JSON/CSV 导出中保留）。
- **统计权威化**：今日时长/会话数改由 Rust 严格本地日界查询返回（不再由活动记录推算）；新增按标签聚合（基于标签快照，改名不改历史）。
- **时长直接输入**：设置页三种时长可直接键入（1–180 整数分钟），Enter/失焦提交、Escape 回退、行内错误提示；保存经串行队列，失败自动恢复上次值。
- **渲染错误兜底**：React 树内任何抛错都会被 ErrorBoundary 捕获，显示可读的错误信息与组件栈（可一键复制 / 重新加载），不再退化为一个全黑窗口。

### 修正
- 计时未到期时调用自然完成接口会被拒绝（CONFLICT），渲染层错误不再可能提前结束专注。
- 修复 `src-tauri/Cargo.toml` 缺失 `[features] custom-protocol`，导致发布构建不内嵌前端资源、运行时回落到 `devUrl`（表现为白屏 / 黑屏）。
- 活动栏排序统一为最旧在上、最新在下，新记录自动滚动定位（1.2 秒月光描边淡出，尊重系统"减少动态效果"与应用内开关）。
- 主内容区纵向间距压缩约 10%，信息密度提升，可点击区域保持 ≥36px。

### 变更
- **行为变更**：计时进行中不再允许直接切换模式（需先结束或重置）——取代 v1.0.0 的"切换即提交"。
- **行为变更**：重置产生的记录为内部记录（abandoned / finish_reason=reset），不出现在活动栏，仅完整导出保留。
- 数据库 schema v2 → v3（就迁移：自动创建标签并回填）；备份格式 v2（继续兼容导入 v1.0.0 旧备份）。
- 设置保存改为串行队列：连续输入/点击时旧请求不再覆盖新值。

### 兼容
- v1.0.0 数据库自动升级到 v3，数据无损；损坏自愈机制保留。
- v1 备份可继续导入（自动补默认标签并回填资格字段）。
- 升级/卸载数据保留行为不变。

## v1.0.0 — 2026-09-04（首个正式版本）

**Abyssal Reverie · 深海绮梦** — 完全离线的 Windows 专注计时器。
Tauri 2.11.5 + React 19 + TypeScript + Rust + SQLite（rusqlite bundled）。

### 核心功能
- **无漂移计时状态机**：剩余时间由 Rust 端 `target_end_at` 墙钟时间戳推导（非逐秒累加），休眠/锁屏/节流自动校正；`revision` 乐观并发防重复触发；`complete_timer` 幂等，完成反馈只触发一次。
- **三段计时**：专注 / 短休 / 长休；切换模式即提交已累积专注时长（completed，计入统计）；「结束本次」为 abandoned 不计入。
- **任务与统计**：任务清单（番茄目标、完成态）、今日目标环、周柱状图、项目分布、连续天数、最佳日；删除任务保留历史（快照 + FK 置空）。
- **海洋视觉**：1080p H.264 无音频循环视频背景（7.7 MB）+ poster 帧兜底；加载失败永不黑屏。

### 系统集成
- **系统托盘 + 后台运行**：关闭窗口即驻留托盘；托盘实时显示剩余时间；开始/暂停/继续/结束/显示窗口全菜单操作；单实例（二次启动聚焦已有窗口）。
- **托盘退出保护（v1.0.0 新增）**：计时中通过托盘「彻底退出」自动冻结剩余时间并恢复为暂停，下次启动由用户手动继续，不悄悄消耗专注时间。
- **开机自启**：默认关闭，设置面板开启（写 Windows 注册表 Run 项，不占数据库）。
- **全局快捷键**：`Ctrl+Alt+Space` 全局开始/暂停；被其它程序占用时启动不崩溃，应用内显示警告横幅，热键降级禁用。

### 数据
- **本地存储**：SQLite 于 `%APPDATA%\com.abyssalreverie.focus\`（bundle identifier 目录，独立于安装目录，升级/卸载均保留）；WAL + 外键 + CHECK 约束。
- **损坏自愈（v1.0.0 新增）**：启动时 `PRAGMA integrity_check`；损坏库自动重命名为 `.corrupt-<时间戳>` 保留以便人工恢复，应用照常以全新库启动。
- **导入导出（v1.0.0 新增）**：全量备份 JSON（含 schemaVersion 校验，旧版备份可导入）、会话 CSV（RFC-4180）；错误导入全量校验后拒绝，绝不覆盖现有数据。
- **schema 迁移**：`user_version` 驱动，v1→v2 就地升级（reduce_motion 列），数据无损。

### 离线与性能
- 完全离线：无任何外部网络请求（CSP 仅 self/asset:/ipc:）；字体/音效/媒体全部内嵌 exe。
- **「降低动态效果」开关（v1.0.0 新增）**：暂停海洋视频降 CPU/电量；窗口隐藏/最小化/系统 reduce-motion 时自动暂停。
- NSIS 安装器含 WebView2 offlineInstaller，无网环境可安装运行。

### 界面
- 玻璃拟态 + 海洋动态背景统一设计令牌；等宽数字（tabular-nums）不抖动。
- 完整 hover/active/disabled 状态与键盘焦点环（focus-visible）；Toggle 带 ARIA switch 语义。
- 通知与声音可在设置中分别关闭，不影响计时与统计。

见 `docs/KNOWN_ISSUES.md`。完整回归记录见 `docs/REGRESSION_REPORT.md`。
