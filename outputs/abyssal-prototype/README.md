# 深海专注 · 管理体验 HTML 原型

打开 `index.html` 即可试用；保留同目录的 `style.css`、`app.js` 与 `assets` 文件夹。

本原型使用原项目的 ocean-poster.jpg，保留深海主题。所有演示数据只存在当前页面内，刷新即恢复初始样例。不会访问真实 SQLite 数据库。

## 建议体验顺序

1. 在任务页搜索 `论文`、`lunwen`、`bdc`，测试名称片段、拼音和首字母查询。
2. 创建任务，再点击项目和标签字段：支持搜索、选择，以及输入名称后就地新建。
3. 点击截止日期体验深色日历、快捷日期、清除与手动输入；修改备注、优先级和预算，取消编辑后重新进入，草稿保留。
4. 从项目页添加任务，默认保持独立；主动选择项目后才绑定。尝试完成仍有待办任务的项目。
5. 删除标签，查看影响说明、解除关联以及 8 秒撤销。
6. 在设置里把单次时长改为 40 分钟：旧任务保留预算，新建任务按 40 分钟计算。
7. 开始专注，暂停、继续、完成并保存；达到预算不自动完成任务。
8. 在设置页启用“模拟下次保存失败”，新建任务后原位重试；删除“阅读”标签后先给任务改选“写作”，再用固定提示撤销，确认不会覆盖新选择。

## 此次细节优化

- 主导航只保留“管理”，管理面板内部左侧分类栏展示任务、项目、标签，记住上次打开的分类。
- 新任务的项目、标签、优先级、截止日期和备注默认未设置。
- 简洁任务行、按需详情、窄屏详情抽屉。
- 全系统磨砂表面与暗色输入、下拉、日历控件。
- 键盘焦点可见，Ctrl/Cmd+K 聚焦搜索，Esc 收起详情或关闭对话框。
- 搜索范围明确、空结果引导、筛选清除、名称重复校验。
- 预算与投入分离，项目归档与标签删除不删除任务。
- 页面内保留独立搜索、筛选、选中状态；编辑草稿保留。创建成功后显示新条目并清除妨碍展示的筛选。
- 归档与恢复保留任务原完成状态；完成正在计时的任务会暂停并解绑。
- 撤销只恢复任务状态，不抹除真实投入。

## 验证与边界

原有 15 项 DOM 逻辑检查、管理回归和批次 0 新增的 3 项检查通过。自动浏览器受管理员安全策略验证失败阻拦，未完成浏览器截图对照、实际键盘和视觉验收，详见 design-qa.md。

这是交互原型，不是正式应用补丁：未实现 Rust 账本、30 秒统计资格、跨休眠恢复、桌面小窗、系统托盘、正式统计与数据迁移。HTML 的计时仅用于体验流程。
